## 👨‍💻 About Me

I'm **Jhon Stiven Caicedo Mosquera**, also known as **Treft**, a Senior Full-Stack Developer with over **3 years of professional experience** building, developing and deploying software solutions.

I specialize in transforming complex requirements into scalable, maintainable and efficient applications, combining modern frontend technologies, backend architecture, database management and infrastructure.

My approach goes beyond writing code: I focus on software architecture, problem-solving, performance, security and delivering real business value.

- 🚀 Full-Stack application development.
- 🧠 Backend architecture, REST APIs and integrations.
- 🎨 Modern, responsive and user-focused interfaces.
- 🗄️ Database design and optimization.
- 🤖 Artificial Intelligence integration and automation.
- 🐳 Docker, Linux and production deployments.
- 🔧 Software maintenance, optimization and scalability.

**My philosophy:** Build solutions that work, scale and make a difference.
